# Casino

Minecraft-Paper-Plugin auf Maven-Basis fuer `1.21+`.

## Erste SlotMachine

1. Stelle ein `LECTERN` auf.
2. Setze direkt darueber ein `OAK_SHELF`.
3. Rechtsklicke das obere Shelf mit einem `LIGHTNING_ROD`.

Dadurch wird das Konstrukt zur ersten SlotMachine. Neben dem Lesepult erscheint ein `LIGHTNING_ROD` als Hebel-Hologramm, und alle drei sichtbaren Shelf-Slots rotieren beim Spin. Wenn der Rahmen abgebaut wird, droppt der Blitzableiter wieder.

## Pferderennen

1. Setze einen `LODESTONE`.
2. Hänge einen `ITEM_FRAME` daran.
3. Setze eine Pferderuestung in den Rahmen.

Danach erscheinen 4 Mini-Racer auf dem Lodestone. Rechtsklick auf den Lodestone:

- mit `1 Emerald` in der Hand: Teilnahme am Rennen
- ohne Emerald: Buch mit Anleitung und Gewinnregeln
